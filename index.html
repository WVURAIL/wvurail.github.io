Real data, real counts — the point is to find out how much of RAIL's identity survives the brand rules, so nothing here is mocked. Components used are stock Design System / Bootstrap 5.3 classes on the DS's 24-column grid. Paper selection follows the old _includes/publications-preview.html: papers flagged highlight: true (every paper if none is flagged), journal-cover papers first, then newest first. Titles break ties inside a year, so the order never depends on how _data/publications.yml happens to be sorted. Built from where / map / uniq / sort / concat only, all present in the Liquid that GitHub Pages' Jekyll 3.9 ships. {% endcomment -%} {%- assign pubs = site.data.publications -%} {%- assign journal = pubs | where: "type", "journal" -%} {%- assign pi = site.data.people.pi | first -%} {%- assign ed = site.data.education -%} {%- assign selected = pubs | where: "highlight", true -%} {%- if selected.size == 0 %}{% assign selected = pubs %}{% endif -%} {%- assign cover_papers = "" | split: "" -%} {%- assign other_papers = "" | split: "" -%} {%- assign years = selected | map: "year" | uniq | sort | reverse -%} {%- for year in years -%} {%- assign in_year = selected | where: "year", year | sort: "title" -%} {%- for pub in in_year -%} {%- comment %}`where` on the title is the one-element array push Liquid lacks; titles are unique in the data file.{% endcomment -%} {%- assign one = in_year | where: "title", pub.title -%} {%- if pub.cover -%} {%- assign cover_papers = cover_papers | concat: one -%} {%- else -%} {%- assign other_papers = other_papers | concat: one -%} {%- endif -%} {%- endfor -%} {%- endfor -%} {%- assign featured = cover_papers | concat: other_papers -%}
{%- comment %} The scrim over the photograph is a flat rgba colour, not a gradient. A CSS gradient is a background-IMAGE, so a checker walking up from the buttons finds no background colour here and reports the light outline button as 1.05:1 on white — a false positive that still lands in a review as a serious violation. A solid rgba composites correctly and looks the same. {% endcomment -%}
